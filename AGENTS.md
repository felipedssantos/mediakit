# Repository Rules & Guidelines

## Mandatory Release Signing
Every production release **MUST** be cryptographically signed. The in-app auto-updater (`@tauri-apps/plugin-updater`) validates signatures against the public key configured in `src-tauri/tauri.conf.json`. Unsigned releases will be rejected by client installations.

- **Private Key**: Kept at `~/.tauri/mediakit.key` (or configured via CI secret `TAURI_SIGNING_PRIVATE_KEY`). Never commit the private key to git.
- **Signing Command**:
  ```powershell
  $env:TAURI_SIGNING_PRIVATE_KEY = "$env:USERPROFILE\.tauri\mediakit.key"
  npm run tauri build
  ```
- **Release Artifacts**: Every GitHub release MUST include:
  - Installers (`.exe`, `.deb`, `.AppImage`)
  - Signature files (`.sig`)
  - `latest.json` manifest generated by the Tauri updater bundle.
