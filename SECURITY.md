# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, open a private security advisory on GitHub:
https://github.com/felipedssantos/conversor/security/advisories/new

Include as much detail as possible:

- Steps to reproduce or a proof of concept
- Affected component (frontend, Tauri capabilities/CSP, Rust backend, or sidecar handling)
- Potential impact

You can expect an initial response within 7 days. Once confirmed, a fix will be
prepared and coordinated before public disclosure.
